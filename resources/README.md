## How to use this collection

1. Pick one learning path rather than collecting every document at once.
2. Read the official source, then explain the main idea in your own notes.
3. Use the practical exercise as a **suggestion**, not evidence of a completed lab.
4. When you complete real cloud work, document the environment, steps, results, and cleanup independently in a project repository.
