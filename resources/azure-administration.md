# Azure administration

> Build conceptual and practical familiarity with the AZ-104 domain.

[← Back to the learning resource index](./README.md)

## Overview

A focused collection for Azure Administrator topics: identity and access, virtual networks, storage, and monitoring. Use these pages as references alongside authorized hands-on practice.

## Recommended official resources

### [AZ-104 official study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-104?wt.mc_id=studentamb_688610)

**Best for:** AZ-104 candidates. Start with the current administrator study guide to determine topic coverage.

### [What is Azure RBAC?](https://learn.microsoft.com/en-us/azure/role-based-access-control/overview?wt.mc_id=studentamb_688610)

**Best for:** Administrators. Learn the relationship among security principals, role assignments, scopes, and role definitions.

### [Azure Monitor overview](https://learn.microsoft.com/en-us/azure/azure-monitor/overview?wt.mc_id=studentamb_688610)

**Best for:** Administrators building operational awareness. Understand metrics, logs, and monitoring experiences.

## Recommended learning sequence

1. Use the AZ-104 objectives to map your study areas.
2. Explore Azure RBAC, then relate resource scopes and least-privilege access.
3. Review virtual network and storage introductions from the Fundamentals guide.
4. Study Azure Monitor and develop a checklist of signals to watch for a hypothetical web workload.

## Practical learning

If you have appropriate Azure access and a cost-controlled environment, create a lab plan covering resource group scope, role assignment, VNet/subnet separation, and basic monitoring. Do not commit subscription IDs, keys, or private configuration details to GitHub.
