## Recommended learning sequence

1. Map DP-700 skills measured to familiar concepts such as ingestion and transformation.
2. Read the Fabric Data Engineering overview and record terminology differences.
3. Plan a small practice workflow using permitted sample data and appropriate Fabric access.
4. Document what was studied, and label any future exercises as complete only after performing them.

## Practical learning

As a learning exercise, outline a possible data workflow from source ingestion to transformation and reporting. Do not describe it as an implemented pipeline until it has been built and tested.
