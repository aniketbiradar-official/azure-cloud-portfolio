# Azure fundamentals

> Start with concepts, then connect them to Azure services.

[← Back to the learning resource index](./README.md)

## Overview

A concise route through cloud concepts and foundational Microsoft Azure capabilities. This guide is useful for readers new to Azure and for AZ-900 revision.

## Recommended official resources

### [AZ-900 official study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-900?wt.mc_id=studentamb_688610)

**Best for:** AZ-900 learners. Use the examination objectives to identify the fundamental concepts and services to learn.

### [Introduction to Azure Storage](https://learn.microsoft.com/en-us/azure/storage/common/storage-introduction?wt.mc_id=studentamb_688610)

**Best for:** Beginners. Learn why Azure offers different storage services and how storage choices relate to workloads.

### [Azure Virtual Network overview](https://learn.microsoft.com/en-us/azure/virtual-network/virtual-networks-overview?wt.mc_id=studentamb_688610)

**Best for:** Beginners moving toward Azure administration. Understand how Azure virtual networks provide connectivity and isolation.

## Recommended learning sequence

1. Review the AZ-900 topic outline and note unfamiliar terms.
2. Compare basic Azure services by purpose rather than memorizing product names.
3. Study how networking, identity, compute, and storage relate within a simple application.

## Practical learning

As a practice exercise, sketch a hypothetical web application and label where its compute, storage, identity, and networking responsibilities would belong. This is a learning exercise, not a deployed solution.
